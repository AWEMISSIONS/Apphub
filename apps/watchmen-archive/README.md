# Watchmen on the Wall archive

Responsive date-indexed archive page reconstructed from the live AWE Missions Watchmen archive after Sites source preparation failed. The page preserves links to the currently hosted PDF reports. If the PDFs are moved to a new host, update `pdfBase` in `app.js`.

The published copy is served at `https://awemissions.github.io/Awe-faith/watchmen/` as part of the AWE Faith Pages site.
