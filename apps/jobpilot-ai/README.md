# JobPilot AI

Private, local-first job search and application organizer. Rebuilds the visible workflows as search links to third-party job boards, saved job/application tracking, hide/restore, next-step reminders, resume/job-description term comparison, and a truthful-claims checklist. No personal profile is prefilled, no resumes leave the browser, no jobs are applied to automatically, and no salary or match claims are fabricated.

No matching source repository was found for this app. The rebuild does not include the original live job-feed integrations or fee estimate because their source and calculation inputs were unavailable; check each external posting for current details.
