# AWE Missions App Hub

A fresh, static recreation of Heath's public App Hub. The original ChatGPT Site remains live while this GitHub Pages version is prepared. The catalog links to the currently published app URLs; Nearby Dining points to its GitHub Pages replacement.

## Contents

- Searchable, category-filtered catalog of live AWE Missions tools and games.
- Current links to Sites still in service, plus GitHub Pages links for the apps already hosted there.
- Direct link back to AWE Faith & Service.
- No login, user tracking, analytics, API keys, or stored personal information.

## Publish

GitHub Actions publishes the root of this repository at `https://awemissions.github.io/Apphub/`. If Pages is not already enabled, set **Settings → Pages → Build and deployment → GitHub Actions**.
